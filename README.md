# 当下时刻 - This Moment

- <https://this-moment.vercel.app>

## Description

"当下时刻 - This Moment" 是一个内容分享平台，专为公共空间设计。用户可以在平台上发布、浏览内容，丰富公共空间的社交和互动体验。目标用户包括公共空间管理者、内容创作者和喜欢社交体验的个人。项目的核心功能包括内容发布、实时互动、内容筛选和分类、社交分享等。

## Key Features

- 用户可以在公共空间内发布内容，分享自己的想法、照片等。
- 支持用户的互动功能，如评论和点赞，增加社交互动。
- 多语言支持、内容筛选和管理，确保内容展示符合空间需求。

## Project Goals

1. 为公共空间提供互动和社交平台。
2. 促进创作者分享内容、获得观众关注。
3. 创建简洁、现代化的 UI/UX 提高用户体验。

## Tech

- 使用 Next.js 全栈开发技术
- 使用 shadcn/ui + TailwindCSS
- 使用 Jotai 状态管理
